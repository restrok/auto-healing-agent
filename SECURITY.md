| Version | Supported          |
| ------- | ------------------ |

## Reporting a Vulnerability

Security is critical to the operation of autonomous infrastructure agents. If you discover a security vulnerability or sensitive information leakage within this project, please follow these steps:

1. **Do not create a public GitHub issue.**
2. Report the vulnerability privately via [GitHub Private Vulnerability Reporting](https://github.com/restrok/auto-healing-agent/security/advisories/new) or contact the maintainer directly.
3. Include:
   - Description of the vulnerability and its potential impact.
   - Steps to reproduce or proof-of-concept.
   - Any proposed remediation or mitigation.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
